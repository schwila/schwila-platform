# 🧠 الخطة الكبرى لبناء منصة "السكويلة"

## 🎯 الرؤية العامة
تمكين أي شخص ناطق بالعربية من تعلّم المهارات التقنية الحديثة — من الصفر حتى الاحتراف — عبر تجربة تعليمية تفاعلية، تطبيقية، ومنظمة.

---

## 📂 محاور المشروع الكبرى

### 1. 🧱 البنية التقنية (الهيكل البرمجي)
- إطار العمل: Next.js + Tailwind CSS
- نظام قراءة محتوى من Markdown
- دعم لاحق لتتبّع التقدّم، المستخدمين، الشارات، إلخ

🔗 انظر: `docs/system-architecture.md`

---

### 2. 📘 المحتوى التعليمي
- هيكل وحدات: Beginner → Intermediate → Advanced → Specialized
- كل وحدة = دروس قصيرة + تمارين + مشروع صغير
- كتابة المحتوى بصيغة Markdown

🔗 انظر: `content/level-beginner/`

---

### 3. 🌐 واجهة المستخدم والمسارات
- تصميم صفحات `/`, `/tracks`, `/tracks/beginner/module-01` إلخ
- مكونات قابلة لإعادة الاستخدام: درس، شريط تقدم، شارات

🔗 انظر: `docs/ui-routing-plan.md`

---

### 4. 🗺️ إدارة المشروع والتخطيط
- وثائق شاملة لكل قسم (`docs/`)
- سجل تنفيذ لكل مرحلة
- تتبع التقدّم داخليًا (Git) مع تواريخ واضحة

🔗 انظر: `docs/master-planning.md`

---

### 5. 🔮 خطط التوسّع المستقبلي
- المساعد الذكي داخل كل وحدة
- واجهة دردشة تعليمية
- تسجيل دخول وتتبع السيرة التعليمية
- واجهة إنشاء مسارات مخصصة
