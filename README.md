# schwila-platform


# 🚀 Schwila – منصة تعليمية تقنية عربية

**Schwila** هي منصة تعليمية موجهة للناطقين بالعربية، تُعلّم أحدث تقنيات البرمجة، الذكاء الاصطناعي، أمن المعلومات، وإدارة الخوادم، من خلال مسارات تفاعلية وتطبيقية منظمة.

---

## ⚙️ التقنية المستخدمة

### 🧩 الواجهة الأمامية (Front-end)
- Framework: Next.js
- تصميم: TailwindCSS
- تفاعلات: Framer Motion + React Hooks

### 🧠 الواجهة الخلفية (Back-end)
- قاعدة بيانات: Supabase (بديل Firebase)
- إدارة محتوى: Strapi (Headless CMS)
- توثيق المستخدمين: Firebase Auth

---

## 🏗️ أقسام المنصة

- 📘 مسارات تعليمية: Python، الذكاء الاصطناعي، الأمن السيبراني…
- 📈 نظام تتبع التقدّم: يُظهر إنجاز المستخدم
- 🧪 اختبارات تفاعلية بعد كل وحدة
- 🏅 شارات ونقاط تحفيزية
- 📜 شهادات رقمية قابلة للتصدير
- 🤖 مساعد تعليمي مدمج عبر ذكاء اصطناعي (لاحقًا)

---
